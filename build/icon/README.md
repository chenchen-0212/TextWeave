# 应用图标

## 图形来源与许可

| 项 | 内容 |
|---|---|
| 基础几何 | [Lucide](https://lucide.dev) 的 `gallery-horizontal-end`（一张主卡片 + 侧后方两张卡片） |
| 原始文件 | `gallery-horizontal-end.svg`（原样保存，作为参考来源） |
| 图标库许可 | **ISC License**（同时以 MIT 提供）—— 允许商用、修改、再分发，**无需署名** |
| 本项目的改动 | 在主卡片内增加了三条文字线（镂空），使语义从「一叠图片」细化为「一叠**图文**卡片」 |

改动属于 ISC 许可允许的范围。基础几何保留自 Lucide，文字线为本项目添加。

## 图形文件

| 文件 | 用途 |
|---|---|
| `app-icon.svg` | **完整版**（24 网格），用于 32px 及以上 |
| `app-icon-small.svg` | **简化版**（24 网格），用于 24px 及以下 |
| `gallery-horizontal-end.svg` | Lucide 原始文件，仅作来源存档 |

### 为什么要有两个版本

完整版包含「两张后卡竖杠 + 三条文字孔」共 5 个特征。在 16px 下，
这些细节会糊成一片白斑 —— 实测过，确实不能看。

所以 ≤24px 换用简化版：一张更大的卡片 + 两条更粗更疏的文字线。
**小尺寸单独出图，而不是把大图缩下去**，这是专业图标集的通行做法。

## 合成方式

应用图标 = 圆角方形渐变底（品牌蓝 `#4F8CFF → #2450D8`）+ 图形的白色版本。

三个技术要点：

1. **每个尺寸单独光栅化**，而不是从 1024 缩下去 —— 缩小会把描边糊掉。
2. **文字是真正的镂空**（用 SVG `mask` 打洞），背景渐变会透出来。
   比画成蓝色横杠更干净，也不会因渐变位置不同而颜色不匹配。
3. **`mask` 里的 `<rect>` 必须显式写 `stroke="none"`**。否则会继承外层
   `<g>` 的白色描边，把黑色填充整个盖住，镂空完全失效 —— 这个坑踩过。

## 重新生成

```bash
cd frontend && npm install      # 需要 devDependency: sharp
cd .. && node scripts/make-icon.mjs        # 或 task icon
```

改图标只需替换 `build/icon/app-icon*.svg` 再跑一次脚本。
**改完务必看 `build/icon/preview/` 里各尺寸的预览再下结论** ——
16px 的问题只有肉眼看得出来。
